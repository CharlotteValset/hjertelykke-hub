# Hjertelykke Hub 

A small web app built with **React + TypeScript + Vite + Tailwind CSS**.  
The project is created as a learning playground and showcase for new features in React, TypeScript and Python (later via API).

## 🚀 Features

- Hero section with:
  - Counter persisted in localStorage
  - Live preview input
- Ideas bank (add + filter by tag)
- Todo list (add, complete, filter, search)
- Stats cards (streak, counts, categories)
- External data fetch (users/events)
- Accessibility & i18n (Norwegian / English)

## 🛠️ Tech stack

- [React 18](https://react.dev/)  
- [TypeScript](https://www.typescriptlang.org/)  
- [Vite](https://vitejs.dev/)  
- [Tailwind CSS](https://tailwindcss.com/)  
- LocalStorage persistence  

## 📦 Installation

Clone the repo and install dependencies:

```bash
git clone https://github.com/<brukernavn>/hjertelykke-hub.git
cd hjertelykke-hub
npm install
```

Start the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

### 🎯 Goals

This project is built as a step-by-step practice project, where each day of coding adds a new feature:

1. Hero with counter + live input
2. Ideas bank
3. Todo list
4. Stats cards
5. Fetch data from API
6. Accessibility & i18n
7. Polish & deploy
